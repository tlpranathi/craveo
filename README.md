# Craveo

Craveo is a full-stack food discovery and ordering platform built using the MERN stack. Users can browse restaurants, explore menus, manage carts, place orders, and track order history through a responsive and modern web interface.

---

# Features

- User authentication with JWT
- Secure password hashing using bcrypt
- Protected backend routes with custom middleware
- Browse restaurants and menus
- Dynamic restaurant search and filtering
- Persistent shopping cart using React Context API + localStorage
- Place orders and track order history
- Cancel pending orders
- RESTful API architecture
- Centralized error handling and standardized API responses
- Responsive frontend UI
